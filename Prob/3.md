### 1. Sample Spaces

**Formal Definition:** * **Discrete Sample Space:** A sample space containing a finite number of possibilities or an unending sequence with as many elements as there are whole numbers (countably infinite).
* **Continuous Sample Space:** A sample space containing an infinite number of possibilities equal to the number of points on a line segment (uncountably infinite).

**Intuitive Explanation:**
A sample space is just the list of every possible thing that could happen in an experiment. 
* **Discrete** means you can count the outcomes. If you are counting items (number of people, number of defective chips, number of coin flips), it is discrete. 
* **Continuous** means you are measuring something. If the answer can have infinite decimal places depending on the precision of your tool (exact time taken to run a race, exact weight of a chemical), it is continuous.

### 2. Random Variables

**Formal Definition:** A function that associates a real number with each element in the sample space.

**Intuitive Explanation:**
Math formulas cannot process physical objects like "Red Balls," "Defective Parts," or "Smith's Helmet." A random variable is a translator. It takes a real-world outcome and assigns a useful number to it so you can perform calculations.

**Key Variant: Bernoulli Random Variable**
When a scenario has exactly two possible outcomes (Success/Failure, Defective/Functional), we assign the number $1$ to one outcome and $0$ to the other. This binary assignment is called a Bernoulli random variable.

**Examples of Translation:**

| Scenario | Raw Outcome (Sample Space) | Random Variable Definition | Assigned Number |
| :--- | :--- | :--- | :--- |
| **Draw 2 Balls** (4 Red, 3 Black) | Red, Red ($RR$) | $Y =$ Number of Red balls | $y = 2$ |
| | Red, Black ($RB$) | | $y = 1$ |
| | Black, Black ($BB$) | | $y = 0$ |
| **Factory Inspection** | Part is defective | $X =$ Defective status (Bernoulli)| $x = 1$ |
| | Part is functional | | $x = 0$ |
| **Returning 3 Helmets** (Smith, Jones, Brown) | Smith gets Jones's, Jones gets Brown's, Brown gets Smith's ($JBS$) | $M =$ Number of correct matches | $m = 0$ |
| | Smith gets Smith's, Jones gets Brown's, Brown gets Jones's ($SBJ$) | | $m = 1$ |
| | All get correct helmets ($SJB$) | | $m = 3$ |

### 3. Probability Distribution / Probability Mass Function (PMF)

**Formal Definition:** The set of ordered pairs $(x, f(x))$ where $f(x) = P(X = x)$, representing the probability that the discrete random variable $X$ equals the exact numerical value $x$.

**Intuitive Explanation:**
Once you have translated outcomes into numbers using a random variable, the PMF tells you the exact odds of getting each specific number. It is an exhaustive list. 

**Added Value (Constraints):**
For a PMF to be valid, two mathematical rules must apply:
1.  Every individual probability must be between $0$ and $1$: $0 \leq f(x) \leq 1$.
2.  The sum of all probabilities must equal exactly $1$ ($100\%$): $\sum f(x) = 1$.

**Example:**
Using the helmet example above, if we calculate the odds of $0$, $1$, or $3$ matches, the PMF looks like this:

| Matches ($m$) | 0 | 1 | 3 |
| :--- | :--- | :--- | :--- |
| **Probability $f(m)$** | $\frac{1}{3}$ | $\frac{1}{2}$ | $\frac{1}{6}$ |

*(Notice that $\frac{1}{3} + \frac{1}{2} + \frac{1}{6} = \frac{2}{6} + \frac{3}{6} + \frac{1}{6} = 1$)*

### 4. Cumulative Distribution Function (CDF)

**Formal Definition:** A function denoted by $F(x) = P(X \leq x) = \sum_{t \leq x} f(t)$ for $-\infty < x < \infty$, which yields the probability that the observed value of a random variable $X$ will be less than or equal to a real number $x$.

**Intuitive Explanation:**
If the PMF is an itemized receipt showing the cost of each item, the CDF is the running total at the bottom. It answers questions like "What is the probability of getting *at most* 2 matches?" by adding up the probabilities of getting 0, 1, and 2 matches.

Because it is a running total, a discrete CDF is always represented as a piecewise "step" function that starts at $0$ and ends exactly at $1$.

**Example:**
Given a random variable $X$ with the following known PMF values: 
$f(0) = \frac{1}{16}$, $f(1) = \frac{1}{4}$, $f(2) = \frac{3}{8}$, $f(3) = \frac{1}{4}$, $f(4) = \frac{1}{16}$

The CDF, $F(x)$, is calculated by accumulating these values:
* $F(0) = f(0) = \frac{1}{16}$
* $F(1) = f(0) + f(1) = \frac{1}{16} + \frac{4}{16} = \frac{5}{16}$
* $F(2) = F(1) + f(2) = \frac{5}{16} + \frac{6}{16} = \frac{11}{16}$
* $F(3) = F(2) + f(3) = \frac{11}{16} + \frac{4}{16} = \frac{15}{16}$
* $F(4) = F(3) + f(4) = \frac{15}{16} + \frac{1}{16} = 1$

Expressed formally as a piecewise function:
$$F(x) =
\begin{cases} 
0, & \text{for } x < 0 \\
\frac{1}{16}, & \text{for } 0 \leq x < 1 \\
\frac{5}{16}, & \text{for } 1 \leq x < 2 \\
\frac{11}{16}, & \text{for } 2 \leq x < 3 \\
\frac{15}{16}, & \text{for } 3 \leq x < 4 \\
1, & \text{for } x \geq 4
\end{cases}$$

**Added Value (Extracting PMF from CDF):**
If you are given the running total (CDF) and need to find the specific cost of one item (PMF), you subtract the previous total from the current total. 
The formula is: $f(x) = F(x) - F(x-1)$

*Proof using the data above:*
To find $f(2)$:
$$f(2) = F(2) - F(1) = \frac{11}{16} - \frac{5}{16} = \frac{6}{16} = \frac{3}{8}$$

### Joint Distribution

**Intuitive Definition:** A joint distribution maps the probability of two or more random events happening at the exact same time. Instead of asking "What are the odds of selling 2 laptops today?", it asks "What are the odds of selling 2 laptops *and* 1 tablet today?". It represents an intersection of outcomes.

**Properties & Formulae:**
For two discrete random variables, $X$ and $Y$, the joint probability mass function is denoted as $f(x, y)$.
* Probability function: $f(x, y) = P(X = x \text{ and } Y = y)$
* Validity rule 1: $f(x, y) \geq 0$ for all pairs $(x, y)$.
* Validity rule 2: The sum of all probabilities in the entire grid must equal 100%: $\sum_x \sum_y f(x, y) = 1$

**Example (Forming the Chart):**
A tech store tracks hourly sales. Let $X$ be laptops sold (0, 1, or 2) and $Y$ be tablets sold (1 or 2). Based on historical data, we map the probability of each specific $(x, y)$ combination. 

| $f(x, y)$ | $X = 0$ | $X = 1$ | $X = 2$ |
| :--- | :--- | :--- | :--- |
| **$Y = 1$** | $0.10$ | $0.20$ | $0.20$ |
| **$Y = 2$** | $0.05$ | $0.15$ | $0.30$ |

*How to read this:* There is a 15% chance ($0.15$) that the store sells exactly 1 laptop and 2 tablets in a given hour. The sum of all six cells is exactly $1.0$.

---

### Marginal Distribution

**Intuitive Definition:**
Marginal distribution is the process of zooming out. If you have a joint distribution grid, the marginal distribution isolates just one variable, completely ignoring the other. You find it by summing the probabilities across the rows or down the columns (placing the totals in the "margins" of the table).

**Formulae:**
* Marginal of $X$ (ignoring $Y$): $g(x) = \sum_y f(x, y)$ 
* Marginal of $Y$ (ignoring $X$): $h(y) = \sum_x f(x, y)$

**Example (Finding Margins):**
Using the joint distribution chart from above, we sum the rows to find the marginal distribution of $Y$, and sum the columns to find the marginal distribution of $X$.

| $f(x, y)$ | $X = 0$ | $X = 1$ | $X = 2$ | **Marginal $h(y)$** |
| :--- | :--- | :--- | :--- | :--- |
| **$Y = 1$** | 0.10 | 0.20 | 0.20 | **0.50** (Sum of row) |
| **$Y = 2$** | 0.05 | 0.15 | 0.30 | **0.50** (Sum of row) |
| **Marginal $g(x)$** | **0.15** | **0.35** | **0.50** | **Total: 1.00** |

*Result:* If you only care about laptop sales ($X$) and ignore tablets entirely, the odds of selling exactly 1 laptop is $0.35$.

### Expectation (Discrete)

**Intuitive Definition:**
Expectation (or Expected Value) is the long-term mathematical average. If you repeated an experiment thousands of times, the average of your results would converge on this number. It is calculated by multiplying every possible outcome by its probability and adding them up.

**Formula:**
$$E(X) = \mu_X = \sum [x \cdot P(x)]$$

**Example:**
Using the marginal distribution of laptop sales ($X$) from the previous table, what is the expected number of laptops sold per hour?
* $P(X=0) = 0.15$
* $P(X=1) = 0.35$
* $P(X=2) = 0.50$

$$E(X) = (0 \cdot 0.15) + (1 \cdot 0.35) + (2 \cdot 0.50)$$
$$E(X) = 0 + 0.35 + 1.00 = 1.35$$
*Conclusion:* On average, the store sells 1.35 laptops per hour. (Note: Expected values do not have to be whole numbers, even if the random variable is discrete).

### Variance and Standard Deviation (SD)

**Intuitive Definition:**
* **Variance** measures how spread out the data is from the expected average. It squares the differences so that negative distances (below average) and positive distances (above average) don't cancel each other out to zero. Because it is squared, its units are distorted.
* **Standard Deviation (SD)** is simply the square root of the variance. It translates the spread back into the original units, telling you the "typical" or "standard" distance an outcome will stray from the average.

**Formulae:**
* Variance shortcut formula: $V(X) = \sigma^2 = E(X^2) - [E(X)]^2$
* Standard Deviation: $\sigma = \sqrt{V(X)}$

**Example:**
Calculate the Variance and SD for laptop sales ($X$). We already know $E(X) = 1.35$.
First, find $E(X^2)$ by squaring the $x$ values before multiplying by probability:
$$E(X^2) = (0^2 \cdot 0.15) + (1^2 \cdot 0.35) + (2^2 \cdot 0.50)$$
$$E(X^2) = 0 + 0.35 + 2.00 = 2.35$$

Now apply the variance formula:
$$V(X) = 2.35 - (1.35)^2 = 2.35 - 1.8225 = 0.5275$$
$$SD = \sqrt{0.5275} \approx 0.726$$
*Conclusion:* The sales typically deviate from the 1.35 average by about 0.726 laptops.

### Covariance

**Intuitive Definition:**
Covariance measures the *direction* of the relationship between two variables. 
* Positive: As $X$ goes up, $Y$ tends to go up.
* Negative: As $X$ goes up, $Y$ tends to go down.
* Zero: They act independently; movement in one doesn't predict the other.
The actual number generated by covariance is difficult to interpret because it is not standardized (it depends on the raw units of $X$ and $Y$).

**Formula:**
$$Cov(X, Y) = \sigma_{xy} = E(XY) - [E(X) \cdot E(Y)]$$

**Example:**
Using the tech store data, do laptop and tablet sales move together? We need $E(X)$, $E(Y)$, and $E(XY)$.
1.  We know $E(X) = 1.35$.
2.  Find $E(Y)$ using its marginals: $(1 \cdot 0.50) + (2 \cdot 0.50) = 1.50$.
3.  Find $E(XY)$ by multiplying $x \cdot y \cdot P(x,y)$ for every cell in the joint grid:
    $$E(XY) = (0 \cdot 1 \cdot 0.10) + (1 \cdot 1 \cdot 0.20) + (2 \cdot 1 \cdot 0.20) + (0 \cdot 2 \cdot 0.05) + (1 \cdot 2 \cdot 0.15) + (2 \cdot 2 \cdot 0.30)$$
    $$E(XY) = 0 + 0.20 + 0.40 + 0 + 0.30 + 1.20 = 2.10$$
4.  Calculate Covariance:
    $$Cov(X,Y) = 2.10 - (1.35 \cdot 1.50) = 2.10 - 2.025 = 0.075$$
*Conclusion:* The covariance is positive ($0.075$), meaning there is a directional trend that when laptop sales are higher, tablet sales also tend to be higher.

---

### Correlation

**Intuitive Definition:**
Correlation is covariance that has been standardized. It takes the clunky covariance number and scales it to fit strictly between $-1$ and $1$. It tells you both the *direction* and the *strength* of the relationship. 
* $1.0$ is a perfect positive lockstep.
* $-1.0$ is a perfect negative lockstep.
* $0.0$ means zero linear relationship.

**Formula:**
$$\rho_{xy} = \frac{Cov(X, Y)}{\sigma_X \cdot \sigma_Y}$$
*(Correlation equals Covariance divided by the product of their individual Standard Deviations).*

**Example:**
To find the correlation of the tech sales, we need the SD of $Y$ to pair with the SD of $X$ ($0.726$) and the Covariance ($0.075$) we already calculated.
1.  Find variance of $Y$: $E(Y^2) = (1^2 \cdot 0.50) + (2^2 \cdot 0.50) = 0.50 + 2.0 = 2.50$.
2.  $V(Y) = 2.50 - (1.50)^2 = 2.50 - 2.25 = 0.25$.
3.  $SD(Y) = \sigma_Y = \sqrt{0.25} = 0.50$.
4.  Calculate Correlation:
    $$\rho = \frac{0.075}{0.726 \cdot 0.50} = \frac{0.075}{0.363} \approx 0.206$$
*Conclusion:* A correlation of $0.206$ indicates a weak positive relationship. They tend to move together, but the link is not very strong.
