# Orthogonal vs. Orthonormal Sets

## 1. Definitions: Orthogonal vs. Orthonormal
In an inner product space, we classify sets of vectors $S = \{ \mathbf{v}_1, \mathbf{v}_2, \dots, \mathbf{v}_n \}$ based on their angles and lengths.

| Term | Definition | Math Conditions |
|------|------------|-----------------|
| **Orthogonal Set** | Every pair of distinct vectors is perpendicular. | $\langle \mathbf{v}_i, \mathbf{v}_j \rangle = 0$ (for $i \neq j$) |
| **Orthonormal Set** | (1) Perpendicular AND <br> (2) Normalized (Length = 1). | $\langle \mathbf{v}_i, \mathbf{v}_j \rangle = 0$ <br> $\|\mathbf{v}_i\| = 1$ |

**Key Theorem:** If $S$ is an orthogonal set of nonzero vectors, then $S$ is linearly independent.
*Translation: Perpendicular vectors never "collapse" into a lower dimension.*

## 2. How to "Normalize" a Set
If you have an Orthogonal set (perpendicular but random lengths), you can turn it into an Orthonormal set by dividing each vector by its own length (norm).

**The Formula:**
$$\mathbf{q}_i = \frac{\mathbf{v}_i}{\|\mathbf{v}_i\|}$$

## 3. Orthogonal & Orthonormal Bases
A **basis** is a set of independent vectors that spans the space.
- **Orthogonal Basis:** A basis where all vectors are mutually orthogonal.
- **Orthonormal Basis:** A basis where all vectors are mutually orthogonal and have length 1.

**Common Examples:**
1. **Standard Euclidean ($\mathbb{R}^n$):**
   $S = \{ (1,0,0), (0,1,0), (0,0,1) \}$ is orthonormal.

2. **Matrices ($M_{22}$):**
   The standard basis $E_1 = \begin{bmatrix}1 & 0\\0 & 0\end{bmatrix}, \dots$ is orthonormal under the Frobenius inner product.

3. **Polynomials ($P_n$):**
   $S = \{ 1, x, x^2, \dots \}$
   > **CRITICAL EXAM TRAP:** This set is Orthonormal **ONLY** if the inner product is defined as the "dot product of coefficients." If the inner product is defined by an Integral (e.g., $\int_{-1}^1 p(x)q(x)dx$), this standard basis is **NOT** orthogonal.

## 4. Finding Coordinates (The Shortcut)
Normally, writing a vector $\mathbf{u}$ as a linear combination of a basis requires solving a system of linear equations (Gaussian elimination). If the basis is orthogonal/orthonormal, you can skip that work.

**Case A: The Basis is ORTHOGONAL**
Use this if vectors are perpendicular but have different lengths. You must "divide out" the length.
$$\mathbf{u} = \frac{\langle \mathbf{u}, \mathbf{v}_1 \rangle}{\|\mathbf{v}_1\|^2}\mathbf{v}_1 + \frac{\langle \mathbf{u}, \mathbf{v}_2 \rangle}{\|\mathbf{v}_2\|^2}\mathbf{v}_2 + \dots$$

**Case B: The Basis is ORTHONORMAL (Best Case)**
Use this if vectors are perpendicular AND length 1. The denominator disappears (because $1^2 = 1$).
$$\mathbf{u} = \langle \mathbf{u}, \mathbf{v}_1 \rangle \mathbf{v}_1 + \langle \mathbf{u}, \mathbf{v}_2 \rangle \mathbf{v}_2 + \dots$$

## 5. Verified Practice Problems

### Problem 1: Finding Coordinates (Orthonormal Basis)
**Given:**
- Basis $S = \{ \mathbf{v}_1, \mathbf{v}_2, \mathbf{v}_3 \}$ in $\mathbb{R}^3$.
- $\mathbf{v}_1 = (0, 1, 0)$
- $\mathbf{v}_2 = (-\frac{4}{5}, 0, \frac{3}{5})$
- $\mathbf{v}_3 = (\frac{3}{5}, 0, \frac{4}{5})$
- Target Vector $\mathbf{u} = (1, 1, 1)$.

**Step 1: Check Orthonormality (Mental Check)**
- $\|\mathbf{v}_2\| = \sqrt{\frac{16}{25} + \frac{9}{25}} = 1$. (Normalized? Yes.)
- $\mathbf{v}_2 \cdot \mathbf{v}_3 = -\frac{12}{25} + \frac{12}{25} = 0$. (Orthogonal? Yes.)
- Verdict: Use the Orthonormal Formula (Case B).

**Step 2: Calculate Coefficients**
Simply dot the target $\mathbf{u}$ with each basis vector.
- $c_1 = \langle \mathbf{u}, \mathbf{v}_1 \rangle = (1)(0) + (1)(1) + (1)(0) = \mathbf{1}$
- $c_2 = \langle \mathbf{u}, \mathbf{v}_2 \rangle = (1)(-\frac{4}{5}) + (0) + (1)(\frac{3}{5}) = -\frac{1}{5}$
- $c_3 = \langle \mathbf{u}, \mathbf{v}_3 \rangle = (1)(\frac{3}{5}) + (0) + (1)(\frac{4}{5}) = \frac{7}{5}$

**Final Answer:**
$$(\mathbf{u})_S = (1, -\frac{1}{5}, \frac{7}{5})$$

### Problem 2: Normalizing & Finding Coordinates
**Given:** An Orthogonal basis (not yet normal).
- $\mathbf{w}_1 = (0, 2, 0)$
- $\mathbf{w}_2 = (3, 0, 3)$
- $\mathbf{w}_3 = (-4, 0, 4)$
- Target $\mathbf{u} = (1, 2, 4)$

**Part A: Normalize to find Basis $v$**
Divide each vector by its norm.
- $\mathbf{w}_1$: Norm is $\sqrt{4}=2$.
  $\mathbf{v}_1 = \frac{(0,2,0)}{2} = \mathbf{(0, 1, 0)}$
- $\mathbf{w}_2$: Norm is $\sqrt{9+9} = \sqrt{18} = 3\sqrt{2}$.
  $\mathbf{v}_2 = \frac{(3,0,3)}{3\sqrt{2}} = \mathbf{(\frac{1}{\sqrt{2}}, 0, \frac{1}{\sqrt{2}})}$
- $\mathbf{w}_3$: Norm is $\sqrt{16+16} = \sqrt{32} = 4\sqrt{2}$.
  $\mathbf{v}_3 = \frac{(-4,0,4)}{4\sqrt{2}} = \mathbf{(-\frac{1}{\sqrt{2}}, 0, \frac{1}{\sqrt{2}})}$

**Part B: Find Coefficients**
Now that the basis $v$ is orthonormal, use the simple dot product formula.
- $\langle \mathbf{u}, \mathbf{v}_1 \rangle = (1,2,4) \cdot (0,1,0) = \mathbf{2}$
- $\langle \mathbf{u}, \mathbf{v}_2 \rangle = \frac{1}{\sqrt{2}} + 0 + \frac{4}{\sqrt{2}} = \mathbf{\frac{5}{\sqrt{2}}}$
- $\langle \mathbf{u}, \mathbf{v}_3 \rangle = -\frac{1}{\sqrt{2}} + 0 + \frac{4}{\sqrt{2}} = \mathbf{\frac{3}{\sqrt{2}}}$

**Final Equation:**
$$\mathbf{u} = 2\mathbf{v}_1 + \frac{5}{\sqrt{2}}\mathbf{v}_2 + \frac{3}{\sqrt{2}}\mathbf{v}_3$$
